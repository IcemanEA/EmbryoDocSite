# Как обновить сайт embryodoc.app

Инструкция для правок текста, фото и стилей и для выкладки новой версии.

## Как устроен сайт

Сайт собирает Ignite — генератор статических сайтов на Swift. Код страницы лежит в `Sources/`, стили и картинки лежат в `Assets/`. Команда `swift run` собирает готовый сайт в папку `docs/`. GitHub Pages показывает содержимое `docs/` из ветки `master` по адресу https://embryodoc.app.

```
Sources/ + Assets/ + Includes/  ──swift run──▶  docs/  ──git push──▶  GitHub Pages  ──▶  embryodoc.app
```

**Главное правило:** не правьте `docs/` руками. Каждая сборка стирает эту папку и создаёт её заново. Всё, что в ней нужно, кладите в `Assets/`.

## Как поменять текст

1. Откройте `Sources/Pages/Home.swift`.
2. Найдите нужную фразу поиском.
3. Замените текст в кавычках. Код вокруг не трогайте.

Пример. Список в карточке «КРИО хранилище» выглядит так:

```swift
FeatureCard(
	image: ("/images/3_cryo.jpeg", "Эмбриолог достаёт канистру из сосуда Дьюара с жидким азотом"),
	title: "КРИО хранилище",
	items: [
		"Электронное хранилище, мужское и женское",
		"Учёт всех единиц биоматериала и история манипуляций",
		"Уведомления об окончании договоров на хранение",
	]
)
```

Чтобы добавить пункт, допишите новую строку в кавычках с запятой в конце.

Два символа в тексте нужно писать особым образом:
- вместо `<` пишите `&lt;`;
- вместо `&` пишите `&amp;`.

Иначе браузер прочитает их как часть разметки. Пример уже есть на странице: «Фрагментация &lt; 10 %».

Правила дизайн-системы для текстов: без эмодзи и восклицательных знаков, тон спокойный и деловой. Вместо тире пишите дефис «-» с пробелами вокруг: «Каждый эмбрион и каждый протокол - в одной системе». Длинное «—» и среднее «–» тире на сайте не используются. В строках вида «Цикл ЭКО · октябрь» разделитель — средняя точка « · ».

## Как поменять фото

**Простой способ: замена с тем же именем.**

1. Подготовьте новое фото с тем же соотношением сторон. Форматы есть в таблице ниже.
2. Сожмите его. Команда сохраняет копию до 1600 px по длинной стороне, обычно это 150–250 КБ:
   ```
   sips -Z 1600 -s format jpeg -s formatOptions 80 новое.jpeg --out Assets/images/2_doctor.jpeg
   ```
3. Соберите и проверьте сайт (раздел «Как проверить на своём компьютере»).

**Фото с новым именем.**

1. Положите файл в `Assets/images/`. В имени используйте латиницу, цифры и `_`, без пробелов.
2. В `Home.swift` или `ProductMocks.swift` замените путь `/images/старое.jpeg` на `/images/новое.jpeg`.
3. Обновите описание фото — вторую строку рядом с путём. Его читают незрячие посетители и поисковики.

| Файл | Где на сайте | Формат кадра |
|---|---|---|
| `1_embryologist.jpeg` | Раздел 01, большое фото | 4:3 |
| `2_doctor.jpeg` | Раздел 02 | 16:11 (подходит 3:2) |
| `3_cryo.jpeg` | Карточка «КРИО хранилище» | 21:9 |
| `4_2_morula.jpeg` | Карточка на первом экране | 4:3 |
| `4_3_blastocista.jpeg` | Экран телефона, раздел 04 | 4:3 |
| `5_reception.jpeg` | Широкое фото, раздел 03 | 3:1 (подходит 21:9) |
| `4_1_2pn_blastomers.jpeg`, `6_patient.jpeg` | Пока не используются | — |

Если пропорции фото и рамки на сайте разные, сайт обрежет края. Поэтому главное в кадре должно быть ближе к центру.

## Как поменять цвета и шрифты

Откройте `Assets/css/embryodoc.css`. В начале файла два блока токенов:
- `:root { … }` — светлая тема;
- `[data-theme="dark"] { … }` — тёмная тема.

Меняйте значения там, а не в стилях ниже. Тогда цвет изменится сразу во всех местах. Цвета берите из дизайн-системы Ledkov.org (`~/Documents/Work/Designs/ledkov/DS`): графит `#2A2825`, синий `#3090E8`, оранжевый `#FF9800`, бумага `#FBFAF8`.

## Как проверить на своём компьютере

1. Соберите сайт в папке проекта:
   ```
   swift run
   ```
   В конце должно появиться «✅ Build completed: docs/». Если вместо этого вывелась ошибка, в ней указаны файл и строка.
2. Запустите локальный сервер:
   ```
   python3 -m http.server 8000 --directory docs
   ```
3. Откройте http://localhost:8000 в браузере.
4. Проверьте страницу. Сузьте окно до ширины телефона и включите тёмную тему кнопкой с луной в шапке.
5. Остановите сервер: Ctrl+C в терминале.

Можно запустить и `ignite run --directory docs --preview`, но только в обычном окне терминала. В Claude Code через `!` эта команда падает: она ждёт нажатия Return, а ввода там нет.

## Как выложить новую версию

```
правки ──▶ swift run ──▶ проверка на localhost ──▶ git commit ──▶ git push ──▶ сборка GitHub Pages (1–2 мин) ──▶ embryodoc.app
               │                  │
               └── ошибка ◀───────┘  исправить и повторить
```

1. Соберите сайт и проверьте его, как описано выше.
2. Посмотрите, что изменилось:
   ```
   git status
   ```
   Изменения должны быть в `Sources/`, `Assets/`, `Includes/` и в `docs/`. Папку `docs/` коммитьте обязательно: GitHub Pages показывает именно её.
3. Добавьте файлы и сделайте коммит:
   ```
   git add Sources Assets Includes docs
   git commit -m "Коротко: что поменяли"
   ```
4. Отправьте на GitHub:
   ```
   git push origin master
   ```
5. Подождите 1–2 минуты. Статус сборки виден на странице репозитория https://github.com/IcemanEA/EmbryoDocSite во вкладке Actions.
6. Откройте https://embryodoc.app и обновите страницу без кэша: Cmd+Shift+R.

Можно попросить Claude Code сделать шаги 1–6 за вас: «собери, проверь и выложи».

## Если что-то пошло не так

| Признак | Причина и решение |
|---|---|
| embryodoc.app не открывается, а адрес `icemanea.github.io/EmbryoDocSite` работает | Пропал файл `docs/CNAME`. Проверьте, что `Assets/CNAME` на месте и содержит `embryodoc.app`. Соберите и выложите заново. |
| На сайте старая версия | Обновите страницу без кэша: Cmd+Shift+R. Проверьте во вкладке Actions, что сборка закончилась. |
| Фото не показывается | Проверьте имя файла и путь. Регистр букв важен: `Photo.jpeg` и `photo.jpeg` — разные файлы. |
| `swift run` пишет ошибку | В тексте ошибки указаны файл и строка. Чаще всего это пропущенная кавычка, запятая или скобка. |
| Вместо текста видны куски разметки | В тексте есть `<` или `&`. Замените их на `&lt;` и `&amp;`. |
